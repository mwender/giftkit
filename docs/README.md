# GiftKit documentation

GiftKit adds a ready-made donation form to Gravity Forms. These pages cover setting it up and the options on each form's **Donation** settings tab.

- [Let monthly donors manage their gift](stripe-customer-portal.md): add Stripe's customer portal link so monthly donors can update their card or cancel on their own.

For what GiftKit does and what it needs, see the [plugin readme](../readme.txt).
