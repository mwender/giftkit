A ready-made donation form for Gravity Forms: one-time and monthly gifts, preset amounts, an optional processing fee and Stripe payments.

== Description ==

GiftKit adds a complete, multi-page donation form to Gravity Forms in one step, and keeps the settings a site owner actually changes on a single Donation tab:

* One-time or monthly gifts
* Preset amount buttons, plus an "Other" amount
* A minimum gift
* An optional "cover the processing fee" checkbox, with your own percentage and note
* Payments through the Gravity Forms Stripe Add-On, with its feeds set up for you

GiftKit requires Gravity Forms and the Gravity Forms Stripe Add-On.

== Installation ==

1. Install and activate Gravity Forms and the Gravity Forms Stripe Add-On, and connect your Stripe account.
2. Install and activate GiftKit.
3. Go to Forms → New Donation Form.
